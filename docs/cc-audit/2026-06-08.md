### [CLAUDE.md] 1.1.1 + 1.2.1 + 1.2.2 + 1.2.10: 缺少 CLAUDE.md

**现状**: 项目根目录无 `CLAUDE.md` 文件。Claude 每次会话从零理解项目结构、构建命令、领域术语，浪费上下文窗口且结论不一致。
**应该**: 有一个 < 100 行的 CLAUDE.md，包含构建命令、测试命令、术语表和设计目标。
**修复方案**:

在项目根目录创建 `CLAUDE.md`：

```markdown
# JLab — 2D 图像标注工具

Rust workspace (3 crates): lab-core（标注数据模型 + 导出）、lab-gui（egui GUI）、lab-utils（工具库）

## 术语表

| 术语 | 含义 | 非此含义 |
|------|------|---------|
| Annotation | 多边形标注数据（点集 + 类别 + 属性），存储为 YAML | ≠ Label（标签文本） |
| ROI | Region of Interest，感兴趣区域标注 | ≠ 普通目标标注 |
| Mode | 编辑模式（Normal / Editing），决定画布行为 | ≠ 编辑器模式 |
| Project | 标注项目 = meta.yaml + images/ + labels/ | ≠ Cargo 项目 |
| Export | 将标注导出为 YOLO / VOC / COCO 格式 | ≠ 序列化 |

## 构建 & 测试

```bash
cargo build --release          # 构建全部
cargo run --release -p lab-gui # 启动 GUI
cargo test --workspace         # 运行全部测试
cargo clippy --workspace       # lint
cargo fmt --check              # 格式检查
```

## 设计目标

1. **标注效率** — 快捷键优先，减少鼠标操作
2. **格式兼容** — 支持 YOLO / VOC / COCO 三种导出
3. **轻量原生** — Rust + egui，无 Electron，启动快

## 设计原则

- 不可变数据优先：标注操作创建新状态，不修改原状态
- workspace 分层：lab-core 无 GUI 依赖，lab-gui 只做展示
- i18n：所有用户可见文本通过 i18n 模块管理

## 仓库规范

- 分支: feature/xxx, fix/xxx
- 提交: conventional commits（feat/fix/refactor/docs/test/chore）
- PR base: master
```

**验证**: `wc -l CLAUDE.md`（应 < 100 行） && `git add CLAUDE.md && git commit -m "docs: add CLAUDE.md"`
**关联**: 此文件修复 §1 全部 P0（1.1.1, 1.1.2, 1.2.1, 1.2.2, 1.2.10）以及 §8 P0（8.1 测试命令）
**来源**: https://docs.anthropic.com/en/docs/claude-code/memory

### [Hooks + Permissions + Large Codebase] 2.1 + 6.3 + 7.1 + 7.2: 缺少 .claude/settings.json + 权限过于宽松

**现状**:
1. 无 `.claude/settings.json`（可提交的团队共享配置）
2. `.claude/settings.local.json` 中 `Bash(bash:*)` 等效于 `Bash(*)`，允许执行任意命令
3. 无 Stop hook 做自动验证
4. 无 deny 规则阻止读取 `target/`、`vendor/` 等构建产物

**应该**: 创建 `.claude/settings.json` 含 hooks + deny 规则；修复 `settings.local.json` 中的过度宽松权限。
**修复方案**:

**步骤 1**: 创建 `.claude/settings.json`（可提交到 git）：

```json
{

    "Stop": [
      {
        "matcher": "",

          {
            "type": "command",
            "command": "bash -c 'git diff --quiet || echo \"⚠ Uncommitted changes detected\"'"

    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [

            "type": "command",

    ]
  },
  "claudeMdExcludes": ["vendor/"],

      "Read(dist/**)",
      "Read(*.pdb)",
      "Read(*.test)",
      "Read(*.bak)"

}
